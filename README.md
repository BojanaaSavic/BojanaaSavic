**Individual project**

A full-stack web application for planning trips, organizing daily activities, managing expenses and budgets, and sharing travel plans with customizable access permissions.

**Technologies:** C#, JavaScript, React, Vite, React Router, Context API, Axios, ASP.NET Core, Entity Framework Core, SQL Server, JWT, HTML, CSS.

### CIM Graph Visualization
**Individual diploma project**

A web application for visualizing a CIM model based on a real ENTSO-E electrical network model, representing complex power-grid data as a graph.

**Technologies:** JavaScript, HTML, CSS.
